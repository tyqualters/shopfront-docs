# Introduction

Vender is the official title for this multi-tenant e-commerce platform portfolio project. The *internal name* would be shopfront. The name was changed to Vender to avoid possible copyright infringement, despite this not being a real-world service.

Multi-tenancy is currently implemented through a single-IBAC (ownership) policy. A user creates a shop, the shop creates products, and anybody can purchase those products. Future plans for RBAC may be considered.

Vender consists of the following projects:

- shopfront (backend)
- databases
- shopfront-react (frontend)
- shopfront-docs (documentation)
