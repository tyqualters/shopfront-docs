# Introduction

This documentation is not a technical reference guide for Vender. Instead, this documentation was created to serve the purpose of describing the design decisions, layout, concerns, intent, and implementation of Vender for each component.

The actual code was written to be self-documenting.

Vender consists of the following projects:

- shopfront (backend)
- shopfront-react (frontend)
- shopfront-runner (CI/CD runner)
- shopfront-docs (this project!)
